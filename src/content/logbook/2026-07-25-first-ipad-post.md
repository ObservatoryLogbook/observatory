I'm testing different ways of publishing observations using nothing but my iPad. Until now, everything has been done from my MacBook, but I have an upcoming trip where I will leave it at home. That means I need a reliable mobile publishing workflow.

At the moment, this little corner of the internet works like this: I write new entries and develop new features on my MacBook, commit the changes to a GitHub repository, and push them online. Netlify then automatically builds and updates the website. While I'm travelling, I don't need to develop new features, I only need to publish new observations and upload images. That workflow, however, needs to be as seamless as possible.

The options I'm currently evaluating are:

- **github.dev** – editing files in a browser-based VS Code environment that works directly against the GitHub repository.
- **github.com** – editing files directly in the repository through GitHub's web interface.
- **Working Copy** – a dedicated Git client for iPad and iPhone, developed in Denmark. Working directly with remote repositories, however, requires the Pro version.

So far, github.dev has worked remarkably well. It connects directly to the repository, and editing Markdown files feels surprisingly natural.

![First iPad image](images/2026-07-25-image-from-ipad.jpeg)

Uploading images currently seems easier through github.com. After copying the image through the iPad's file system and converting it to JPEG format, I can simply upload it to the repository and reference it from the Markdown file.

The biggest drawback of github.dev is that autocorrect is disabled. I understand why: in a development environment, autocorrect could easily become more annoying than helpful. Still, I have grown accustomed to relying on it for capitalization and minor spelling corrections, so writing feels just a little slower. Perhaps that's not entirely a bad thing; it might encourage me to keep these observations concise.

Tomorrow, I'll put Working Copy through its paces.

Oh, and the image? It's a jigsaw puzzle of Paris. I lived there for three and a half years, and the city will always hold a very special place in my heart. Solving jigsaw puzzles is one of my favourite ways to unwind and be mindful. Oddly enough, my favourite part is always the sky.
